# JARVIS AI Assistant

A Python-based desktop AI assistant with voice interaction, wake-word detection, GUI support, automation, and AI-powered features.

## Features
- Voice commands
- Wake-word detection
- AI chat
- Screen reading
- Code generation
- WhatsApp automation
- GUI interface
- Mobile connectivity

## Technologies
- Python
- PyQt
- Speech Recognition
- Text-to-Speech
