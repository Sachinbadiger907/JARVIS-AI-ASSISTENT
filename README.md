# 🤖 JARVIS AI Assistant

A powerful Python-based desktop AI assistant inspired by intelligent virtual assistants. JARVIS combines voice recognition, AI conversation, desktop automation, screen reading, code generation, and productivity tools into a single application.

---

# ✨ Features

### 🎤 Voice Assistant
- Wake-word detection
- Voice command recognition
- Natural text-to-speech responses
- Voice profile enrollment

### 🧠 AI Intelligence
- AI-powered conversations
- Code generation
- Intent detection
- Smart command processing

### 💻 Desktop Automation
- Open applications
- Close applications
- Execute desktop commands
- Background execution

### 📖 Screen Reader
- Read on-screen text
- Explain screen content
- Accessibility support

### 💬 Communication
- WhatsApp messaging support
- Mobile connectivity

### 🖥 GUI
- Desktop interface
- Status display
- Binary animation
- Voice status indicator

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/Sachinbadiger907/JARVIS-AI-ASSISTENT.git
```

## Open Project

```bash
cd JARVIS-AI-ASSISTENT
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

# ⚙️ Configuration

This project uses environment variables for API keys.

Create a `.env` file and add your own API keys.

```
OPENAI_API_KEY=YOUR_KEY
GEMINI_API_KEY=YOUR_KEY
ANTHROPIC_API_KEY=YOUR_KEY
```

> **Important:** Never upload your `.env` file to GitHub.
